### Key Findings

- **Tests 19-22 fix**: Upload after conflict resolution is unnecessary on GRTS — UseCloud makes local=cloud (nothing to upload), UseLocal auto-uploads internally. Uninitialize releases the device.
- **"Post-merge regressions" were transient**: Tests 47, 78, 83, 86, 89, 91-93, 95-101, 103 all pass with clean state. Only 19-22 needed YAML fixes.
- **Test 83**: Needs 600s timeout (large 100MB+ dataset). Passes with adequate time.
- **Tests 67-69**: Sign-out tests now pass (previously failed due to user setup issues).
- **Test 75**: Entity auth golden path passes (transient failure previously).
- **Test 12 miscategorized**: Retry+SyncLastSavedData auto-response works on Xbox. Test passes.
- **Xbox CS background upload**: Does NOT sync to PlayFab cloud for cross-device access. Only explicit UploadWithUiAsync propagates cross-device. Test 03 passes in isolation but can fail in batch runs due to residual cloud data.
- **GRTS conflict detection non-functional on devkit** (tests 38, 42): Tested 5 separate approaches — (1) auto-reinit/AddUser after cloud change, (2) fresh init after upload, (3) write-after-upload before uninit, (4) Xbox system provider with fresh init, (5) Upload when cloud has diverged. In ALL cases, GRTS either downloads cloud silently (no conflict callback) or uploads local silently (overwriting cloud). Root cause: `PFXGameSaveFreeConfig` during Uninitialize resets sync metadata, and GRTS never does compare-and-swap during upload. Test 14 (conflict local wins) is a FALSE PASS — it doesn't validate content. These tests require retail Connected Storage with system-level sync tracking.
- **Batch test isolation**: Running tests sequentially can cause cloud contamination. Tests that pass individually may fail in batch due to residual PlayFab cloud data from prior tests. Proper cloud cleanup (DeleteSaveRoot + UploadWithUiAsync) at test start prevents this.
- **Xbox progress state callbacks**: Not fired by Xbox Connected Storage. Test 36 will never pass on Xbox.
- **Xbox CS contention re-sync**: After eviction, Xbox CS uses cached local data instead of re-downloading from cloud. Tests 05, 11, 82 affected.
- **Xbox CS ↔ GRTS are completely separate backends**: Xbox `PFGameSaveFilesAddUserWithUiAsync` requires XUser handle (CS path). Calling with PersistedLocalId returns ERROR_NOT_SUPPORTED (0x80070032). Data uploaded via Xbox CS is not visible to GRTS and vice versa. Tests 76, 108-112 cannot work with one Xbox device + one PC device — they require both devices to use the same backend (e.g., two PCs on GRTS).
- **Test 34 flaky**: Cancel during upload is timing-dependent on Xbox. If cancel fires before Xbox CS background cloud sync completes, cloud never gets the data. Retry upload returns S_OK (no-op since local state matches committed state). DeviceB sees 0 files. Passes ~50% of the time.

### Batch Run Recommendations

To run tests reliably in batch/sequence:
1. Reboot Xbox between batches: `xbreboot /x:10.0.0.104` + `xbconnect 10.0.0.104 /ws`
2. Reset storage before each test: `xbstorage /x:10.0.0.104 reset /force`
3. Clean local PC save folder: `Remove-Item "C:\gamesaves-test\*" -Recurse -Force`
4. For cross-device tests, add cloud cleanup to test startup: DeviceB should `DeleteSaveRoot` + `UploadWithUiAsync` before the main test flow begins
5. Allow adequate delay between tests (cloud propagation can take 5-10s)
