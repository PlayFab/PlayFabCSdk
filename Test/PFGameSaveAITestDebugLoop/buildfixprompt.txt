Rules for the JSON:
- "rebuild": set true if you made changes that need compiling (you should have — you just fixed build errors), so the loop rebuilds. If you could NOT fix the build, set rebuild to false so the loop stops instead of looping. The loop reads this flag and halts immediately on false, so use it deliberately rather than guessing "true" to look productive — a false "true" just burns another build cycle on an unchanged tree.
- "rerun": keep the same list of test IDs that still need to be re-run once the build succeeds (the tests you were originally fixing). Do not drop them just because the build failed.
- Write this file LAST, only once you are finished. Overwrite any existing aidebugresult.json.
